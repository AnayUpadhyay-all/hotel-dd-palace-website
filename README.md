# Hotel DD Palace Concept

This repository contains a professional website concept for **Hotel DD Palace** in Anpara, Sonbhadra.

## Digital Gaps Addressed
*   **Lack of Official Website:** This concept serves to replace third-party directories as the primary point of truth.
*   **Mobile Experience:** The site is heavily optimized for mobile (which drives most local searches) with a sticky "Call" CTA.
*   **Clear Information Architecture:** Information (Rooms, Dining, Events, Location, Reviews) is clearly segmented, unlike the scattered information on mapping sites.
*   **Direct Contact Paths:** Click-to-call functionality is ubiquitous to encourage immediate booking/enquiries over phone (the verified primary contact method).
